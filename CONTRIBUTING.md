# Contributing

Kea is a product, not a community-maintained library. The live service is [https://kea.chat](https://kea.chat).

## External contributions

We do not accept unsolicited pull requests. If you have an idea, a bug in the public site, or a partnership proposal, email **[team@kea.chat](mailto:team@kea.chat)** or use [https://kea.chat/contact](https://kea.chat/contact).

Security issues belong in [SECURITY.md](SECURITY.md), not in public issues.

## Product name

Write the product as **Kea**. The GitHub path `shooper69/KEA` is the repository id only.

## If you work on this repository

- Keep Kea isolated: this repo is Kea only (GitHub `shooper69/KEA`, site [kea.chat](https://kea.chat)).
- Do not commit secrets, tokens, `.env` files, or `.kea/` credentials.
- Match existing TypeScript, React, and CSS style. Prefer small, product-shaped changes.
- Public copy should stay companion-voiced: Kea is not a course, tutor, or classroom.
- After UI that ships in Vite `dist`, note whether a new Play Store AAB is required.
